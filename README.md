# Setrum: Electricity Usage Tracker

A web application concept for real time household electricity tracking and bill estimation. Built by a five person team for the Human and Computer Interaction course at BINUS University, starting from user research and a product requirement document, then a high fidelity Figma prototype, then this HTML, CSS, and JavaScript build.

## My role on the team

User research, the product requirement document, and the usability evaluation. I led a System Usability Scale (SUS) test that scored the prototype in the excellent range, and authored a heuristic evaluation that identified key interface issues to improve.

## Pages

- **Home** (`index.html`): overview of connected appliances and current usage
- **Bill Estimation** (`bill-estimation.html`): estimates the monthly electricity bill from usage
- **Notification** (`notification.html`): usage alerts and reminders
- **Profile** (`profile.html`): user account and settings

## Tech stack

HTML, CSS, and vanilla JavaScript, using Chart.js for usage charts, based on a Figma prototype.

## How to view

Open `index.html` in a browser.
